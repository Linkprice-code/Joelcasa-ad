# 조엘까사 광고 운영 개선 제안

## 사용
index.html을 브라우저에서 열면 제안서를 확인할 수 있습니다. 이미지가 내장되어 인터넷 없이도 열립니다.
상단 목차, 오른쪽 아래 이동 버튼, 키보드 좌우 방향키로 섹션을 이동합니다. 인쇄 버튼으로 PDF 저장이 가능합니다.

## GitHub Pages 업로드
1. 저장소 루트에 index.html과 .nojekyll을 업로드합니다.
2. 저장소 Settings → Pages에서 Deploy from a branch를 선택합니다.
3. main 브랜치, /(root)를 선택해 저장합니다.
4. 배포 완료 후 표시되는 주소를 공유합니다.

## 구성 및 기준
- 10개 섹션: 표지, 진단 요약, 개선안 6개, 실행 계획, 성과 검증.
- 반응형 레이아웃과 인쇄 스타일 포함. 외부 코드 라이브러리 불필요.
- 계정 진단과 수치는 사용자 제공 자료입니다. 실제 계정에 접속하여 감사한 결과가 아닙니다.
- ROAS 1,000%는 운영 목표이며 보장 성과가 아닙니다.
- 스마트스토어 직접 열람이 제한되어 공식몰 joelcasa.com의 침구 이미지와 브랜드 표현을 참고했습니다. 컬러는 공식 규정이 아닌 제안서 디자인 해석입니다.
- 공식 로고 이미지 대신 JOELCASA 텍스트를 사용했습니다.
- 이미지 출처: https://joelcasa.com/web/product/medium/201710/588_shop1_572805.jpg
- 브라우저 시각 검수는 실행 환경 제한으로 수행하지 못했습니다. HTML 구조·링크·스크립트 구문을 검사했습니다.

## 수정 사항
- 담당자: 링크프라이스 나민호 대리
- 현재 문제·개선안 본문은 문장별로 분리하고 데스크톱에서 같은 행의 시작선을 정렬
- 핵심 문제·실행 항목·목표 수치는 굵기와 은은한 배경으로 강조

## 시각 중심 개편
- 본문을 현재/개선 비교, 핵심 숫자, 짧은 실행 카드로 재구성했습니다.
- 6개 개선안의 상세 원문은 각 항목의 펼치기 영역에 보존했습니다.
- 실제 성과 그래프가 아닌 방향 도식이며, ROAS는 현황과 목표를 구분했습니다.
- 담당자는 링크프라이스 나민호 대리입니다.

## 큰 글자 슬라이드 개편
- 10장 좌우 슬라이드: 하단 이전/다음, 키보드 ←/→, 모바일 좌우 스와이프 지원.
- Home/End 키로 처음/마지막 이동. 상단 목차·링크는 해당 슬라이드로 이동.
- 제목 약 29–40px, 핵심 수치 60–70px, 주요 본문 18–22px로 확대.
- 아이보리·올리브·브라운 톤 및 대비 강화. 작은 화면에서는 슬라이드 안을 세로 스크롤할 수 있습니다.
- 상세 설명은 펼치기 지원. 인쇄/PDF는 모든 슬라이드를 출력합니다.
